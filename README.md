# chrispaur.com

Die Website von Christoph Paur.

## Wie es hier funktioniert

Was in diesem Ordner liegt, ist die Website. Wird hier etwas geaendert,
veroeffentlicht GitHub Pages die Seite automatisch neu, in der Regel
innerhalb einer halben Minute. Kein FTP, kein Plesk.

    index.html    die Seite selbst
    favicon.svg   das kleine Zeichen im Browser-Tab
    CNAME         die eigene Domain (kommt beim Umschalten dazu)

teampaur.com hat mit diesem Projekt nichts zu tun und liegt woanders.
